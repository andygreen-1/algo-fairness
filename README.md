# algo-fairness
Resources related to algorithmic fairness:

- `algo_fairness_references.md`: a list of papers and other reference materials relevant to algorithmic fairness
- `credit_modeling_demo.ipynb`: a reference document that does two things:
  - Demonstrates how to work with various packages related to model evaluation, interpretability, and debiasing
  - Provides brief explanations/refreshers on key concepts relevant to the demo
- `disparate_impact_testing_framework.md`: an example framework that lenders can use to conduct disparate impact testing and mitigate fair lending risk
